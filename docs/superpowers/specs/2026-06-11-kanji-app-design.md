# 일본어 상용한자 학습 앱 (N5~N2) — 설계 문서

날짜: 2026-06-11
상태: 사용자 승인됨

## 1. 목표와 배경

일본어 상용한자(JLPT N5~N2, 약 1,000자)를 파생 구조로 학습하는 오프라인 앱.
기본자(예: 木)에서 파생된 한자(休, 林, 森, 禁, 相 …)를 그룹 단위로 묶어 학습한다
(참고 교재: 한자 1자당 훈음·구성 원리·음독/훈독·예시 단어를 한 페이지에 정리한 형식).

- 사용자: 본인 + 가족/지인 (스토어 배포 없음, URL 공유로 설치)
- 기기: Android + iOS 스마트폰 (PWA로 양쪽 모두 지원)
- 설치 후 완전 오프라인 동작 필수

## 2. 확정된 결정 사항

| 항목 | 결정 |
|---|---|
| 플랫폼 | PWA (홈 화면 설치형 웹앱) |
| 배포 | GitHub Pages 무료 호스팅, URL 공유 |
| 데이터 | 오픈 데이터 기반 자동 구축 + 수동 보정 오버라이드 |
| 표시 언어 | 한국어 훈음("쉴 휴") + 한국어 뜻 |
| 읽기 표기 | 음독·훈독 모두 히라가나 (가타카나 사용 안 함) |
| 학습 화면 | A안 교재형 (정보 한눈에) |
| 복습 화면 | B안 플래시카드형 (탭하여 공개, 알아요/몰라요) |
| 퀴즈 방식 | 객관식 4지선다 |
| 진도 관리 | 한자별 정답률 기록, 틀린 문제 우선 출제 (본격 SRS 아님) |
| 동기화 | 없음 — 진도는 기기별 IndexedDB 저장 |

## 3. 데이터 파이프라인 (빌드 타임, PC에서 실행)

공개 데이터를 가공해 앱에 내장할 JSON 번들을 생성하는 스크립트.
앱 사용 중에는 절대 네트워크에 접근하지 않는다.

### 입력 소스
- **KANJIDIC2** (EDRDG, CC BY-SA): 한자별 음독/훈독, JLPT 급수, 획수
- **JMdict** (EDRDG, CC BY-SA): 단어 사전 — 급수별 어휘 목록과 교차해 예시 단어 추출
- **JLPT 급수별 한자/어휘 목록** (공개 정리본): N5~N2 범위 결정
- **IDS 한자 분해 데이터** (CHISE IDS 등): 한자 → 구성요소 분해. 파생 그룹 자동 생성의 근거
- **Tatoeba** (CC-BY): 일본어 예문 + 한국어/영어 번역. 급수 어휘만 포함된 쉬운 문장 우선 선별
- **한국 훈음 데이터** (libhangul hanja.txt 등 공개 훈음 DB): "쉴 휴" 형식의 한국식 훈음

### 파생 그룹 생성 규칙
1. IDS 분해로 각 한자의 구성요소를 구한다.
2. 기본자(부수 또는 N5~N2 내 단순 한자)별로, 그것을 구성요소로 포함하는 한자를 그룹핑한다.
3. 한 한자가 여러 그룹에 속할 수 있으면 대표 그룹 1개를 규칙(가장 의미 있는 구성요소)으로 정한다.
4. 자동 결과는 `data/overrides/groups.json` 으로 수동 보정 가능 (그룹 이동, 이름, 설명, 순서).

### 출력 (앱 내장 JSON)
- `kanji-{level}.json`: 한자별 {자형, 훈음(한국어), 뜻, 음독[], 훈독[], 획수, 급수, 그룹 id, 설명(선택)}
- `words-{level}.json`: 단어별 {표기, 읽기(히라가나), 한국어 뜻, 포함 한자, 급수}
- `sentences-{level}.json`: 예문별 {일본어 문장, 대상 단어, 읽기, 한국어 번역}
- `groups.json`: 그룹별 {기본자, 이름(예: "木의 파생"), 소속 한자 id 목록, 급수 범위}
- 예상 총 크기: 수 MB 이내 (오프라인 캐싱 무리 없음)

### 품질 보정
- 자동 생성 결과 중 훈음 누락·이상한 그룹은 오버라이드 파일로 수정
- 빌드 시 검증: 모든 한자가 정확히 1개 그룹에 속하는지, 훈음/읽기 누락 여부 리포트

## 4. 앱 구조 (PWA)

### 화면
1. **홈**: 급수(N5~N2) 탭 → 파생 그룹 카드 목록 ("木의 파생 12자", 진도율 표시)
2. **학습 모드 (교재형, A안)**: 그룹 내 한자를 순서대로. 카드 구성:
   - 상단: 그룹명 + 진행 위치 + 급수 배지
   - 큰 한자 + 한국어 훈음 + 구성 원리 설명(있으면 표시. 자동 생성되지 않으며 `data/overrides/` 에 수동 입력한 한자만 표시 — 기본은 비어 있음)
   - 음독(히라가나) + 예시 단어 2~3개(읽기·뜻)
   - 훈독(히라가나) + 예시 단어
   - 같은 그룹의 다른 파생 한자 칩 (탭하면 이동)
3. **복습 모드 (플래시카드, B안)**: 한자만 표시 → 탭하면 훈음·읽기 공개 → 알아요/몰라요 기록. 출제 범위는 그룹/급수 선택.
4. **퀴즈 모드** (4유형, 모두 4지선다):
   - ① 단어 발음: 단어 제시 → 히라가나 읽기 4개 중 선택
   - ② 단어 뜻: 단어 제시 → 한국어 뜻 4개 중 선택
   - ③ 문장 읽기 (JLPT 漢字読み): 문장 속 밑줄 한자 단어 → 읽기 선택
   - ④ 문장 표기 (JLPT 表記): 문장 속 밑줄 히라가나 → 올바른 한자 선택
   - 오답 보기 자동 생성: 발음 문제는 비슷한 읽기(장음/탁음/요음 변형, 같은 한자의 다른 읽기 조합), 표기 문제는 모양이 비슷한 한자(같은 그룹/같은 구성요소 우선)
   - 퀴즈 종료 후 결과 화면: 점수 + 틀린 문항 해설(해당 한자 카드 링크)
5. **오답 노트**: 정답률 낮은 한자 목록 → 바로 복습/퀴즈 재출제

### 진도 데이터 (IndexedDB)
- 한자별: 노출 횟수, 정답/오답 횟수, 마지막 학습 시각, 학습 완료 플래그
- 그룹별 진도율은 한자 기록에서 계산
- 출제 가중치: 오답률 높은 한자 우선, 미학습 한자 다음, 정답률 높은 한자 가끔

### 오프라인/PWA
- 서비스 워커가 앱 셸 + 전체 JSON 데이터를 설치 시 프리캐시
- 업데이트: 온라인 상태에서 접속하면 새 버전 자동 갱신 (버전 표시)
- manifest.json: 홈 화면 설치, 세로 모드, 앱 아이콘

## 5. 기술 스택

- Vite + React + TypeScript (정적 SPA)
- 서비스 워커: vite-plugin-pwa (Workbox)
- 저장소: IndexedDB (idb 라이브러리)
- 스타일: CSS (경량, 프레임워크 없음) — 모바일 우선, 다크 모드 지원
- 데이터 빌드 스크립트: Node.js (TypeScript), `scripts/build-data/` 에 위치
- 배포: GitHub Pages (gh-pages 브랜치 또는 Actions)

## 6. 에러 처리

- 데이터 로드 실패(캐시 손상 등): 재다운로드 안내 화면
- IndexedDB 사용 불가(사파리 프라이빗 모드 등): 메모리 저장으로 동작하되 "진도가 저장되지 않음" 경고 표시
- 퀴즈 출제 풀 부족(예문 없는 단어 등): 해당 유형 제외하고 출제

## 7. 테스트

- 빌드 스크립트: 파생 그룹 생성, 훈음 병합, 검증 리포트에 단위 테스트
- 앱 로직: 오답 보기 생성, 출제 가중치, 진도 기록에 단위 테스트 (Vitest)
- UI: 핵심 흐름(학습 → 퀴즈 → 오답 기록) 컴포넌트 테스트
- 수동 확인: 실제 iPhone/Android에서 홈 화면 설치 + 비행기 모드 동작 확인

## 8. 범위 제외 (YAGNI)

- 손글씨 쓰기 연습, 획순 애니메이션 (추후 고려)
- 계정/서버/기기 간 동기화
- 본격 SRS(망각 곡선) 스케줄링
- N1 한자, 음성(TTS) 재생
- 스토어 배포
